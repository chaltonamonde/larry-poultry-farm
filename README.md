# Larry Poultry Farm 🐔

A modern, high-performance web application and digital storefront for **Larry Poultry Farm** — an agribusiness breeding commercial layers, improved Kienyeji chickens, day-old chicks, farm-fresh eggs, and quality feeds based along the Kiambu–Thika highway corridor in Kenya.

---

## 🌟 Key Features

- **Farm Catalogue & Ordering**: Browse farm-fresh eggs, vaccinated day-old chicks, live & dressed broilers, point-of-lay pullets, feeds, and organic poultry manure.
- **Hatchery Reservation Calendar**: Real-time batch reservation system for day-old chicks with hatch dates, breed specifications, and deposit requirements.
- **Interactive Cart & Checkout**:
  - Live county & town delivery fee calculator (Nairobi, Kiambu, Thika, Nakuru, Eldoret, etc.).
  - Free delivery threshold calculator.
  - Simulated Daraja M-Pesa STK Push payment and Pay-on-Delivery options.
  - Automated WhatsApp order formatting and dispatch scheduling.
- **Wholesale & Standing Orders**: Dedicated quote request portal for hotels, restaurants, schools, and supermarkets.
- **Poultry Management & Brooding Advice**: Curated agribusiness guides covering brooding schedules, vaccination timetables, feeding regimens, and biosecurity protocols.
- **Agribusiness Design System**: Tailored dark-mode agribusiness aesthetics with charcoal and deep forest green themes, subtle glowing accents, and mobile-optimized touch controls.

---

## 🛠️ Technology Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Dev Server**: Vite
- **Styling**: Vanilla CSS with custom tokens & CSS variables
- **Icons**: Lucide React
- **Linter**: Oxlint

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/chaltonamonde/larry-poultry-farm.git

# Navigate into the project folder
cd larry-poultry-farm

# Install dependencies
npm install
```

### Running Locally

```bash
# Start Vite development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Building for Production

```bash
# Type check and build production bundle
npm run build

# Preview production build locally
npm run preview
```

The production output is generated in the `dist/` directory with relative asset paths ready for deployment on any static host or web server.
